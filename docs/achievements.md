## 备注
- 黄饼（yellowcake）：铀矿粉用硫酸浸出得到的铀浓缩物（U3O8），因为颜色和形状像黄色的蛋糕得名，**不能吃**，有微弱放射性。核链条上：铀矿 → 粉碎机磨成铀矿粉 → 硫酸浸出成黄饼 → 加氟化氢变六氟化铀 → 离心机浓缩。
