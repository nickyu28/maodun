# 猫盾工业：跟现实对不上的地方（作者 11-01 要我查；只列，没点头不改）

我对着 js/19-industry.js 的配方表（IND_RECIPES、IND_CRAFT、IND_EL_RECIPES）和 js/19-industry-nuke.js 的配方查的。分三类：对得上的、对不上要改的、对不上但当游戏可以留的。

## 一、对得上的（不用动）
- 熔点：铁 1538、铜 1085、锌 420、锡 232、铅 327、黄铜／青铜 950、钢 1550、砖 900、陶罐 600、木炭 400、玻璃加草木灰 1000／纯沙子 1700（电炉）。
- 黑火药：硫 + 木炭 + 硝石（硝石最多）。
- 黄铜 = 铜 + 锌；青铜 = 铜 + 锡。
- 盐水电解出氢气、氯气、烧碱；水电解 2 氢 : 1 氧；熔融盐 801°C 出钠和氯气。
- 氟化氢 = 萤石 + 硫酸；硫酸 = 二氧化硫 + 氧 + 水；铀矿粉用硫酸浸出成黄饼；黄饼 + 氟化氢 → 六氟化铀；浓缩到 3.5%、5%（现实的低浓铀）。
- 铝要电解（任务 33）；钻石用高压从碳压出来（人造钻石就是这样）。
- 铅围裙、铅箱挡辐射；氯气有毒云；天然气遇火炸。
- 水煮海水出盐；甘蔗熬糖。
- 电池 = 铜 + 锌 + 盐水（伏打电池）；电池串联电压叠加。

## 二、对不上，建议改（按重要程度排）
1. **矿直接烧成金属，没有还原剂**（中，影响前期节奏）：铁矿、铜矿、锡矿、锌矿放进窑，到熔点就出金属。现实里矿是氧化物或硫化物，要碳（木炭、焦炭）才能还原出金属，锌矿要先焙烧、锌 907°C 就沸腾了。建议：每份矿多要 1 份木炭（或煤）；锌、锡的温度改成 950、1200。**会影响整个前期经济，要作者拍板。**
2. **钚的提取用硫酸**（中）：现实是用**硝酸**溶解乏燃料再萃取（PUREX）。游戏里有硝石 + 硫酸能做硝酸，正好接上。建议：加一个配方"硝石 + 硫酸 → 硝酸"，钚配方改成乏燃料棒 + 硝酸。
3. **发电机（`dev_gen`）烧炉子出 12 V**（中）：现实里炉火的热要靠蒸汽机／汽轮机才能发电；热电偶（塞贝克效应）电压很低。建议：改名"热电发电机"，输出降到 3～6 V；或者加一条"要水"（烧水出蒸汽）才有 12 V。
4. **电磁线圈的配方用铅**（低，**这是我自己的锅**）：现实里电磁铁是铜线绕在**铁芯**上，铅没用。我当时是为了给铅找用处。建议：磁石 2 + 铜线 10 + 铁锭 1（铁芯）。铅可以用在别处（电池、屏蔽）。你同意我就改任务 32。
5. **面包直接用小麦**（低）：现实里要先磨成面粉、发酵再烤。建议：小麦进粉碎机出面粉；面包 = 面粉 + 盐 + 水，温度 200～230°C。
6. **奶酪要 100°C 加热**（低）：现实里做奶酪是 30～35°C 加凝乳酶，加热到 100°C 是做乳清奶酪。建议把 minT 降到 40，放着慢慢做（时间长）。
7. **石油燃料值**（低）：一桶石油 600、煤 150，差 4 倍；现实里石油热值只比煤高大约 1.5 倍。可以改成 250，但这是游戏平衡，随你。
8. **油点会再生**（低）：现实里油井会枯。游戏为了好玩留着也行；要的话让油点用完就没了、地图上随机换地方。

## 三、对不上但当游戏可以留
- 设备过压"爆炸"半径 3 米：现实里是烧坏。
- 并联电压取最高：现实里电压不同的电源并联会互相倒灌。
- 钢靴、鞋的倍数、药的效果。
- 燃料棒一次烧几个游戏日，反应堆熔毁阈值 400°C。

## 四、我建议加的（现实有、游戏没有）
- **硅**：沙子 + 碳在电炉（1700°C）里还原出硅。现实里的芯片和太阳能板都是硅，不是锗和镓；锗是早期晶体管（真实的历史），镓配砷化镓是太空太阳能电池。建议加硅，给芯片和太阳能板用，沙子终于有第三个用途，元素表加一格（Si）。
- **电动鼓风机**：现实里存在（电动鼓风机、风机），任务 51。

## 五、已经做了的新东西，核对结果
- 塑料 = 石油 + 氯气 → PVC，人造革 = PVC 涂在布上：对得上。
- 锂电池 3 V：对得上（锂锰一次电池 3 V）。
- 手摇发电机 6 V：对得上（磁石 + 线圈）。
- 小型核电放燃料棒：对得上（像 RTG，同位素热电池）。
- 太阳能板用锗、镓：太空太阳能电池是这样，但地面用硅；见上面第四类。
