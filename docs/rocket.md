# 火箭（通关目标）设计稿（作者 11-01：看现实；主线只有一条，大部分内容通关不需要）

## 设计原则（作者定）
- **明面上只有一句话：游戏开始时写"去外太空"**，之后不主动提示，**屏幕上不常驻目标栏**。想知道怎么去，**按 Tab 键调出进度表**：里面列着火箭的每一样部件（见下面"进度表"），带领玩家，但不教怎么做。其它所有东西（自动化、元素表、核电……）都在暗处，让玩家自己发掘。（作者 11-01 定：不然他自己在我帮助下都没法打。）
- **更多的东西在暗处**：绝大多数物品、设备、元素、配方，通关**不需要**。人是为了搭自动化、点亮元素表、折腾核电玩下去的，火箭只是个指引（像 Minecraft 的末影龙）。所以火箭的路径要窄，别把全部新东西都塞进火箭配方里。
- 火箭本身要有"暗处的深度"：能算、能优化，不是凑够材料就行。

## 现实里的火箭（要点）
- 火箭 85～90% 的重量是燃料。发射不是"飞上去"，是要把速度加到约 **9.4 千米/秒**（到近地轨道），一级火箭做不到，所以要**分级**：烧完一级就扔掉，二级接着加速。
- 速度变化的公式（齐奥尔科夫斯基）：**Δv = 比冲 × 9.8 × ln(起飞总重 ÷ 烧完后的重量)**。比冲越高越省燃料：煤油 + 液氧约 300 秒，液氢 + 液氧约 450 秒。
- 煤油（RP-1）从石油分馏来，液氧、液氢是气体压缩冷却成液体：氧气 −183°C，氢气 −253°C。要冷到这么低，现实里靠液化空气一级一级预冷，空气分离还会顺手分出氮、氩、氖、氪。
- 现实里发射台还要有火焰导流槽、避雷塔、加注管路，这个游戏里只保留"一块大平地 + 发射塔"。

## 游戏里的版本（默认，没反对就照做）
**材料与新东西**（每个都要有通关以外的用途）：
- **空气分离塔**（设备，电 24 V，耗电大）：吸空气，分出氮气瓶、氧气瓶、氩气瓶，微量氖、氪。元素表氮、氖、氩、氪几格由它点亮。氮气、氩气另有用途（保护气、炼钢、灯泡）；也是自动化玩家的一条新链。
- **冷凝机**（设备）：把氧气瓶压缩降温成**液氧罐**（要压缩机 + 氮气预冷）；氢要先用液氮预冷到 −196°C，再降到 −253°C 成**液氢罐**。液氧、液氢也是燃料之外的东西：液氮能冷冻保存食物（以后）。
- **石油分馏塔**（设备，要热，不用电）：石油桶 → 煤油 + 汽油 + 沥青。煤油做火箭一级燃料；汽油、沥青另有用途（发动机燃料，车、铺路，以后）。
- **火箭发动机**（部件，工作台）：钢 + 钛 + 铜 + 电机。两种：**煤油发动机**（比冲 300，推力大，做一级）、**氢氧发动机**（比冲 450，推力小，做二级）。
- **燃料罐**（部件）：铝（或钢）+ 塑料保温；装液氧、煤油、液氢。
- **舱体和整流罩**（部件）：铝 + 玻璃 + 塑料；舱体里放载荷（一只猫，哈哈：可选的彩蛋，不影响通关）。
- **发射台**（设备，半径 6，放在基地里一块平地上，周围 8 米内不能有别的东西）+ **发射塔**（高处，外观，装配时要用）。

**装配与计算**（暗处的深度）：
- 在发射台上一级一级往上叠：一级（发动机 + 燃料罐）、二级（发动机 + 燃料罐）、舱体。每一级的燃料装多少，自己决定。
- 界面实时显示每一级的**干重、燃料重、比冲、推重比**，和**总Δv**（按上面公式算）。推重比 < 1 点火起不来；总Δv ≥ 9.4 千米/秒才能入轨。
- 算得不够会怎样：Δv 不够，升到半空烧完，掉回来炸（发射台炸坏，要重修，已装的东西没了）；多放燃料罐会变重，推重比下降。**实验是主要的乐趣，也是暗处的深度。**
- 重量取值：材料各自一个重量（钢重、铝轻、塑料轻），写进文档，数字让 Code2 定到"凑齐 9.4 刚好够，多一点余量"的程度。

**发射和通关**：
- 点火，10 秒倒计时（所有人听得到），火箭升起，镜头（第三人称）跟着升，拉远，出"入轨成功"的画面和一句话。
- 通关**不结束游戏**，可以继续玩；画面最后写一句"第 1 章　完"（作者说以后可能有第 2 章：去外太空生存，现在不做，只在文字上留个位置）；元素表、自动化、核电都还在。通关给一个称号"火箭工程师"（要接进 `myTitle()`、`aiRandomTitle()`，CLAUDE.md 有规定，Code2 做的时候看一下）。
- 联机（作者 11-06 改）：**一艘火箭可以载多人，也可以合伙造**。
  - 谁都能往发射台上装部件。
  - 舱体有座位数：一个舱体坐 1 人，多载人要多装舱体（或大舱体）。
  - 每个乘客加一点质量（草稿 0.1 吨），拉低总 Δv 和推重比。
  - 点火前 10 秒倒计时里，人在发射台范围内的才上船。
  - 通关对船上所有人算，每个人拿"火箭工程师"；没上船的不算。
  - 载荷里放猫的彩蛋照旧，也算一份质量。
  - "第 1 章　完"那一屏列出这艘火箭的乘客名字。

完整的 42 步和数量见 docs/rocket-steps.md（草稿，数字让 Code2 调）。

## 进度表（Tab 键，作者 11-01 定；11-01 又改：步骤要完整，但道路是一点一点点亮的，前面的路一开始是未知）
- 按 Tab 打开／关闭，触屏设备右上角按钮栏加一个"进度"按钮（跟"配方""背包""元素表"并排）。Tab 键在猫盾工业里现在没被占用。不常驻、不弹、不挡画面。
- 标题"进度　去外太空　发现 k / n"（k = 已经点亮的东西数，n = 总数）。下面是火箭的几个大格子：发射台、一级、二级、舱体、燃料；**一开始每个格子都是"？？？"，不写名字**。
- **每一样都往下展开成完整的步骤树**，一路写到最原始的资源：
  - 每个部件一行：`名字 ×数量　←　在哪里做（工作台／大窑／电炉／电解槽／压力机…）：需要的材料 ×数量（温度、时间、电压）`。
  - 它需要的材料，如果也是做出来的，缩进一格接着展开它自己的做法；展开到只能挖／采／捡的资源为止，那一行写"在哪里找"（山地、盐湖沙漠、远征地图的哪种资源点）。
  - 同一个东西有多种做法（木炭／煤／焦炭任选、铝或钢）合成一行写"任选"。
  - **颜色（作者 11-01 定）**：这一行要的数量，玩家**现在手上够了**（背包 + 仓库箱里加起来 ≥ 需要的数量）就写成**绿色**，不够就是**灰色**。每行后面写"有 X / 需要 Y"（不只靠颜色，色盲也看得出）。需要的数量要一路往下乘（比如一级发动机要 2 个，每个要钢 8，钢那一行就写需要 16）。父项已经够了（绿色）的，它下面的做法折叠起来，不用再往下看。标题里显示"发现 k / n"，见下面"点亮规则"。
- **数据来源是游戏里现有的配方表**（`IND_CRAFT`、`IND_RECIPES`、`IND_EL_RECIPES`、核电的配方，和后面新加的设备配方），不是手写一份：从每个火箭部件往下递归，这样配方改了，进度表自动跟着变，不会过时。要防死循环（桶、瓶子做完会还回来，当基础物品直接显示，不展开）。
- 不需要新的存档字段：颜色是按**现在**背包和仓库箱里的数量算的，不是"拿到过"，所以东西用掉了又会变回灰色（这是对的，进度表看的是现在还差什么）。
- 最后一行小字："其它的，自己找。"（元素表、核电、自动化这些暗处的东西不放进这张表。）
- 这是一张**照着做就能通关的路线图**，所以步骤要完整；但是玩家不想看就不用看。

### 点亮规则（作者 11-01 定："发现了该道路的第一个东西（如芯片）则点亮一个，前进的道路依然未知"）
- 进度表是一棵树（火箭部件 → 它的材料 → 材料的材料 → …）。**一开始整棵树都是"？"**。
- 玩家**第一次拿到树里的任何一样东西**（挖到、做出来、捡到、哪怕只是一点点）：从这样东西**一直往上到火箭部件**的整条路径点亮——显示名字、数量、做法；用到它的上一层东西也显示名字。
- 这条路径上每个点亮的东西，**它自己的做法**（需要哪些材料）显示出来，但它的材料里**还没拿到过的，名字仍然是"？"**（只写"？ ×数量"，数量让玩家有个概念）。玩家拿到了那样材料，它才点亮、它自己的做法才展开。
- 兄弟分支、更下面的东西，没拿到之前一直是"？"。所以**前进的道路是一步一步被发现的，不是一次摊开**；但每一步点亮以后，那一步的做法是完整的（多少个、怎么做、什么东西）。
- 已点亮的东西，颜色规则照上面：现在手上够了绿色，不够灰色。
- 数据：存档白名单字段 `B.seen`（拿到过的物品 key 的集合），**拿到过就算**，扔了也不会重新变成"？"。老档读档时按背包里现有的东西补一部分。
- 标题里的"发现 k / n"：k = 点亮的东西数，n = 树里一共多少样东西（n 暴露了总数，但不暴露内容；作者不想要的话改成不显示 n）。
- 配方书里的东西照旧自己翻，和进度表无关。


## 火箭之后（作者 11-06：可以去别的星球，有不同的东西）
- **草稿，没排期**：入轨以后可以去别的星球，每个星球有不同的资源、环境和东西。这就是"第 2 章"。
- 现在只定方向，不做。要做之前先和作者对一遍：去哪几个星球、怎么落地和回来、哪些东西只有那边有。
- **作者 11-07 定的方向**：先月球，再火星；以后可以**自定义行星**（回头再聊，现在不设计、不排）。
- **协调者的骨架（草稿，作者没反对的才算数）**：
  - （作者 11-07 改，取代"远征图、撤离点回基地"）每颗星球是一张**固定的地图**：上飞船之后选一个位置当基地，**基地以后不会移动，地图上的资源不会刷新**（挖完就没了）。地貌、资源、温度各不相同。
  - 去别的星球要的 Δv 比入轨（9.4 千米/秒）更大（月球约 +3.1、火星约 +3.6，粗数），玩家要再造更大的火箭、多加一级；接在第 1 章的 Δv 计算上，不另起一套。
  - 生存靠氧气和温度，不加辐射。月球没空气：要氧气瓶（空气分离塔产的氧气，多一个用处）和宇航服；月球白天 +120°C、夜里 −170°C，重力约 1/6。火星：空气稀薄（二氧化碳）、平均 −60°C、重力约 0.38、土是红的（氧化铁）、有尘暴。
  - 现实依据找得到的新东西：月壤电解出氧气；钛铁矿出铁和钛（接火箭要的钛）；极地水冰；火星二氧化碳做燃料（Sabatier 反应）。
  - 怪少而轻：月球放不伤人的"月兔"；火星不放怪，尘暴是危险。
  - 一艘火箭载多人，几个人一起去。能不能回地球、多人怎么选落点，见下面"还没定"。
  - **目标（作者 11-07 定）**：到了月球以后，明面的目的依旧是**去别的星球**（火星）。暗处的两个：**地窖徽章**（要用镁做）和**插旗**（每面旗占一个位置，把整个月球插满算隐藏成就；旗杆不能用木头，月球没有树，草稿用铝杆或镁杆 + 布）。
  - 月球矿（草稿，作者没反对）：钛铁矿（铁、钛、氧）、斜长岩（铝、硅、钙）、橄榄石（镁）、KREEP 岩（钾、磷、稀土）、陨石铁镍块（天然铁镍）、陨硫铁（硫）。氦-3 不做。硅：地球多（地壳约 28%，月壤约 20%），月球不靠硅。
  - **推进顺序（作者 11-07）**：必须 地球 → 月球 → 下一个星球（火星）一站一站推进，不能跳过月球直接去火星。草稿：存档记"去过月球"，火星要这个才能去。
  - **月球的暗处目标（作者 11-07 改）**：插旗（插满 225 格）和**电子电路**（在月球上做出来，配方同地球）。电路要硅（月壤有）、玻璃板（月壤烧）、铜线和硝酸（月球上没有）：铜、硝酸要从地球带（带物资有重量，是道算术题），或者月球上给一点点铜，等拆任务时定。
  - 地球上的"设备块"（任务 74，n×n 个 1 米方格，3×3～9×9 米）是地球随机地图的钉块办法，月球整张图固定，不用它。插旗的格子叫"旗格"（40 米），别跟"块"混。
  - **已定（作者 11-07）**：
    1. **能回地球**。回程燃料要在月球上自己造（水冰或钛铁矿出氢氧），这样资源不刷新也不会卡死，回程也是一件要算的事。
    2. 多人：**一艘火箭一个落点，队友共用一块基地区域**。
    3. 选落点的时候**只看地貌，看不到矿**；能看到水（水冰）、凹槽（月溪、撞击坑）这类地形，矿要自己探。（现实里轨道遥感也是先看到地形和极地的水冰。）
    4. 插旗：月球图 600×600，每格 40 米，**15 × 15 = 225 格**，一面旗占一格，插满 225 格算隐藏成就。
    5. **（作者 11-07 改）地窖徽章删掉**（物品和隐藏成就都不要了）。**呼叫月球车来接你回基地**这个功能留着：现实可行（紧急信标加自动驾驶，复用任务 50），要电池；路上月球车可能出事。草稿：一个"求救信标"物品，按下呼叫，月球车（要有一辆、电够）自动开来接；名字和做法等拆任务时定。镁不再为徽章用，仍有旗杆、镁合金燃料罐、镁条。
    6. 资源总量：**每种矿至少是"把整棵科技树做完所需"的 3 倍**，由 Code2 算。
  - **带物资上飞船（作者 11-07）**：可以把地球上的东西装进飞船带去月球，**会增加重量**，要算进火箭的总质量（拉低 Δv 和推重比）。所以旗杆、种子、布、木头都可以从地球带，但带得越多燃料越要多。每样东西的重量表草稿让 Code2 定，写进文档。
  - **月球上有"月壤"，不是土**：月壤是细碎、带玻璃碴的岩石粉，没有有机物、没有水，**不能直接种地**。现实里已有实验：嫦娥四号在密封舱里让棉花种子发芽；2022 年佛罗里达大学在月壤里种出拟南芥，但长得弱。游戏里：月壤 + 肥料（用 KREEP 岩出的钾、磷）+ 水 + 密封暖棚才种得出，长得比地球慢。月壤用处：电解出氧、烧结成砖、种植基质。火星的土还有高氯酸盐（有毒），要洗过才能种，留到火星再说。
  - **货运火箭（作者 11-07）**：可以造只能搭载物品的火箭（没有舱体、不载人），从地球往月球补给；铜、硝酸这类月球上没有的东西，从地球运过去（地球上到处都是）。拆分路线图见 docs/moon.md。
