# 火箭（通关目标）设计稿（作者 11-01：看现实；主线只有一条，大部分内容通关不需要）

## 设计原则（作者定）
- **明面上只有一句话：游戏开始时写"去外太空"**，之后不再提示，**不放目标栏、不放部件清单**。怎么去、要什么，全靠玩家自己发掘（作者 11-01 定：好玩的东西要自己找）。
- **更多的东西在暗处**：绝大多数物品、设备、元素、配方，通关**不需要**。人是为了搭自动化、点亮元素表、折腾核电玩下去的，火箭只是个指引（像 Minecraft 的末影龙）。所以火箭的路径要窄，别把全部新东西都塞进火箭配方里。
- 火箭本身要有"暗处的深度"：能算、能优化，不是凑够材料就行。

## 现实里的火箭（要点）
- 火箭 85～90% 的重量是燃料。发射不是"飞上去"，是要把速度加到约 **9.4 千米/秒**（到近地轨道），一级火箭做不到，所以要**分级**：烧完一级就扔掉，二级接着加速。
- 速度变化的公式（齐奥尔科夫斯基）：**Δv = 比冲 × 9.8 × ln(起飞总重 ÷ 烧完后的重量)**。比冲越高越省燃料：煤油 + 液氧约 300 秒，液氢 + 液氧约 450 秒。
- 煤油（RP-1）从石油分馏来，液氧、液氢是气体压缩冷却成液体：氧气 −183°C，氢气 −253°C。要冷到这么低，现实里靠液化空气一级一级预冷，空气分离还会顺手分出氮、氩、氖、氪。
- 现实里发射台还要有火焰导流槽、避雷塔、加注管路，这个游戏里只保留"一块大平地 + 发射塔"。

## 游戏里的版本（默认，没反对就照做）
**材料与新东西**（每个都要有通关以外的用途）：
- **空气分离塔**（设备，电 24 V，耗电大）：吸空气，分出氮气瓶、氧气瓶、氩气瓶，微量氖、氪。元素表氮、氖、氩、氪几格由它点亮。氮气、氩气另有用途（保护气、炼钢、灯泡）；也是自动化玩家的一条新链。
- **冷凝机**（设备）：把氧气瓶压缩降温成**液氧罐**（要压缩机 + 氮气预冷）；氢要先用液氮预冷到 −196°C，再降到 −253°C 成**液氢罐**。液氧、液氢也是燃料之外的东西：液氮能冷冻保存食物（以后）。
- **石油分馏塔**（设备，要热，不用电）：石油桶 → 煤油 + 汽油 + 沥青。煤油做火箭一级燃料；汽油、沥青另有用途（发动机燃料，车、铺路，以后）。
- **火箭发动机**（部件，工作台）：钢 + 钛 + 铜 + 电机。两种：**煤油发动机**（比冲 300，推力大，做一级）、**氢氧发动机**（比冲 450，推力小，做二级）。
- **燃料罐**（部件）：铝（或钢）+ 塑料保温；装液氧、煤油、液氢。
- **舱体和整流罩**（部件）：铝 + 玻璃 + 塑料；舱体里放载荷（一只猫，哈哈：可选的彩蛋，不影响通关）。
- **发射台**（设备，半径 6，放在基地里一块平地上，周围 8 米内不能有别的东西）+ **发射塔**（高处，外观，装配时要用）。

**装配与计算**（暗处的深度）：
- 在发射台上一级一级往上叠：一级（发动机 + 燃料罐）、二级（发动机 + 燃料罐）、舱体。每一级的燃料装多少，自己决定。
- 界面实时显示每一级的**干重、燃料重、比冲、推重比**，和**总Δv**（按上面公式算）。推重比 < 1 点火起不来；总Δv ≥ 9.4 千米/秒才能入轨。
- 算得不够会怎样：Δv 不够，升到半空烧完，掉回来炸（发射台炸坏，要重修，已装的东西没了）；多放燃料罐会变重，推重比下降。**实验是主要的乐趣，也是暗处的深度。**
- 重量取值：材料各自一个重量（钢重、铝轻、塑料轻），写进文档，数字让 Code2 定到"凑齐 9.4 刚好够，多一点余量"的程度。

**发射和通关**：
- 点火，10 秒倒计时（所有人听得到），火箭升起，镜头（第三人称）跟着升，拉远，出"入轨成功"的画面和一句话。
- 通关**不结束游戏**，可以继续玩；画面最后写一句"第 1 章　完"（作者说以后可能有第 2 章：去外太空生存，现在不做，只在文字上留个位置）；元素表、自动化、核电都还在。通关给一个称号"火箭工程师"（要接进 `myTitle()`、`aiRandomTitle()`，CLAUDE.md 有规定，Code2 做的时候看一下）。
- 联机：**每个人在自己的基地造自己的火箭**，各自通关；以后再想合作发射再说。
