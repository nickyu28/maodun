# 2D 猫盾闯关（大厅小游戏）· 设计文档

状态：**草稿，等作者点头再写代码**（11-01 夜 Code1）。

## 是什么
大厅广场里一台"闯关机"。横版平台闯关，1～4 人合作，没有 AI 队友。不算模式：不进模式列表、不弹模式规则卡、不受"第三人称"那条约束。
奖励第 3 期再定：前两期不发猫盾币、不进商店、不进成就。以后除了它和现有跑酷，不再做别的小游戏。

## 怎么进
- 闯关机摆在广场跑酷对面，走近（`HUB.proximityRange` 以内）弹按钮「2D 闯关」，跟走近公告板一样的做法（`hubProximityTick`）。
- 点了打开闯关画面（全屏 DOM 层 `#pf-screen`）：上面是"等人"区，下面「开始」。
  - 没组队：直接一个人开。
  - 组了队（`lobbyParty`）：点的人当这局的**房主**，给同队、此刻也在大厅的人发邀请条（10 秒，「加入 / 不了」）；房主看到谁进来了，随时点「开始」，不用等齐。最多 4 人，多的进不来。
  - 不在同一队的人看不到邀请，想一起玩先组队（跟其他模式一致）。
- **中途加入**：一关打到一半不能进；房主过关的结算页上会给同队还在大厅的人再发一次邀请，下一关开始时一起进。
- 退出：右上角「退出」回大厅广场，原地站在闯关机前。房主退出 = 这局结束，其他人看到"房主走了"回大厅。
- 新手教程没做完（`gState.tutDone` 为假）时闯关机不响应，跟组队一样。

## 画面
- 用现有的 Three.js 画：单独一个场景 + 正交相机侧视，镜头只沿 x 跟着大家的中点走（人散太开就按领先的人，落后的超出屏幕左边 → 拉到镜头边上）。
  进闯关时大厅停画（加进 `hubPanelCovers` 的列表），出来接着画，不用拆大厅。
- 角色直接用 `raceMakeBody`：自己戴 `mySkinColor()` / `gState.acc` / `myFace()` / 自己的宠物；别人戴 `peerFaceOf()` / `peerAccOf()`；
  肤色和宠物现在 `ROOM_HELLO` 里没有，放进闯关自己的 `PF_JOIN` 消息里带过去（不改 `ROOM_HELLO`）。宠物纯装饰，跟在身后飘。
- 地形用方块（平台、刺、移动台、终点旗），一关一张手写的数据表（字符画），放在新文件里。

## 操作
- 键盘：A/D 或 ←/→ 走，W/空格/↑ 跳（按得久跳得高），S 下蹲穿过薄台；E 复活（站在倒下的队友身边按住）。第 2 期加 J 技能。
- 触屏（`gState.control === 'pad'`）：左下左右两个大按钮（不用摇杆，横版只要左右），右下「跳」「救」；第 2 期加「技能」。按钮放在 `#pf-screen` 自己里面，不借用竞速/超燃的按钮。
- 进去时退出指针锁定，出来再恢复。

## 第 1 期玩法：一个关卡、跑跳盾、互相复活
- 每人 3 格血。碰刺 / 被小怪撞 -1 并短暂无敌；掉出屏幕底下直接倒下。
- **盾**：按住 K（触屏「盾」）举盾，正面挡住小怪的弹丸（第 1 期只挡，不反弹，反弹是第 2 期盾猫的技能），举盾时走路变慢。
- **倒下**：0 血不死，原地变"等救"状态 15 秒；队友站旁边按住「救」2 秒 → 1 格血站起来。15 秒没人救或掉出屏幕 → 出局，看别人玩；到下一个检查点自动复活。全队都倒下 → 回最近的检查点重来，不扣东西。
- **一个人玩**：没人能救，倒下直接回检查点（不等 15 秒）。
- 一关：3 段 + 2 个检查点 + 终点旗，单人 3～5 分钟。全员（还活着的）碰到旗就过关，结算页写用时和倒下次数。

## 第 2、3 期（先写个方向，到时再出细文档）
- 第 2 期：进门选角色（同一局不能重复）——盾猫（盾能反弹弹丸）、冲刺猫（短冲刺过宽沟）、爪猫（近战打小怪）、奶猫（站着回队友血、救人只要 1 秒）；关卡做到 4～5 关，有些地方得靠某个技能才过得去（但一个人玩时那段换成普通路）。
- 第 3 期：Boss 关、奖励（作者定）。

## 联机
- **房主权威**：房主跑怪、移动台、检查点、过关；每个人自己算自己的移动和碰撞（手感不卡），10 Hz 发 `PF_ME`（位置、朝向、举盾、血、状态）。
  怪、弹丸、移动台用"开局时间 + 同一个种子/同一张表"各自算，房主每 1 秒发一次 `PF_WORLD` 校正（怪的位置和血，偏得远就直接对齐）。
- 伤害谁说了算：自己被打自己判（自己的画面里撞到就算），这样延迟高的人也不会"明明躲开了还掉血"；打怪、救人发事件给房主确认（`PF_EV`），房主广播结果。
- 别人的位置插值显示（跟大厅 `hubOnMe` 一样的做法，延后 100 毫秒画）。房主 5 秒没消息 → "房主掉线了"，全员回大厅。
- 消息：`PF_INV`（邀请）、`PF_JOIN`（加入，带肤色和宠物）、`PF_START`（关卡号、开始时间、名单）、`PF_ME`、`PF_WORLD`、`PF_EV`、`PF_END`。都走现有的 `bc.postMessage`（房间房主转发），收到先看发送人在不在这局名单里，不在就丢。
- **NET_PROTO**：新加了消息类型，旧版本收到不认识的会直接忽略，严格说可以不加；但为了不让新旧版本的人同队进了闯关机一个能玩一个没反应，**第 1 期上线时 11 → 12**，在 `01-core.js` 的版本说明里加一行。

## 冒烟（自己等条件成立，不靠固定等待）
- PF1：走到闯关机前 → 按钮出现 → 进闯关、一个人开局 → 用脚本把人放到旗前、按右走 → 等到"过关"结算出现；`gState.pf.best` 有值，刷新还在。
- PF2：两个标签页组队，房主进闯关机、队员收到邀请点加入 → 两边名单都是 2 人 → 开局，两边都看到对方的猫盾、戴着对方的配饰。
- PF3：联机里队员血打到 0 → 房主那边看到"等救" → 房主走过去按住救 → 两边都看到队员 1 格血站起来；再一次不救 → 15 秒后出局、到检查点复活（用脚本把计时调快，不真等 15 秒）。
- PF4：触屏模式进闯关：左右、跳按钮能用（`touchPath` 按住），0 个页面错误。另外跑一遍两项 B6（新文件改了加载顺序）。
- PF5：一个人倒下直接回检查点；全队倒下回检查点。

## 第 1 期验收
1. 广场里看得见闯关机，走近能进，一个人能从头玩到旗、看到用时。
2. 两台设备（或两个标签页）同队能一起进、一起玩，互相看到外观，能互相复活。
3. 手机上能玩（左右、跳、盾、救都有按钮），电脑键盘能玩。
4. 中途不能加入；关与关之间能加入（第 1 期只有一关，就是"再来一次"时能加入）。
5. PF1～PF5、B6 两项都过；全量冒烟不比之前多挂。
