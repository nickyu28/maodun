**pic1 格式**（作者手绘的草图：一个方框，左边一个标题，右边一个对勾）：设置页里这三项每一项是一个**选项列表**，每个选项一行，**当前选中的那一行右边画一个对勾**；点哪一行选哪一行，不是下拉框、不是滑条。用 `settingsRegister` 的 `type: 'choice'`，渲染成这种"一行一个、选中打勾"的样子（你在 `js/02b-settings.js` 里把 `choice` 的画法改成这样，别的 choice 也用这个样子，保持一致；触屏每行 ≥ 44 像素高）。
1. **画质（低、中、高、超高）**：控制**画面渲染的上限和模型细节**——低：`renderer.setPixelRatio(1)`、关抗锯齿、关阴影、几何体少分段；中：像素比 ≤ 1.5、抗锯齿开、阴影关；高：像素比 ≤ 2、阴影开（低分辨率阴影图）；超高：像素比 = 设备原生、阴影高分辨率、几何体多分段（圆柱、球的分段数）。默认**中**，设备差的（`navigator.hardwareConcurrency` ≤ 4 或 `deviceMemory` ≤ 4）默认**低**。你查现有渲染器创建的地方（js/03-world.js 约 165 行 `new THREE.WebGLRenderer(...)`、各模式自己建的场景、`setPixelRatio`、阴影、`THREE.*Geometry` 的分段数）接上去；改了即时生效能做的就即时生效，做不到的（要重建渲染器）就写"下次进游戏生效"。
2. **视野（正常、稍远、远、超远）**：控制**能看多远**——相机的 `far` 和雾的距离（`scene.fog`、`FogExp2` 的浓度）按档位乘 1、1.4、2、3（正常是现在的值）；**视野越远，场景里同时画的东西越多**，要跟画质一起提示。
3. **流畅度（正常、流畅、高）**：控制**帧率目标**——正常 30、流畅 60、高 120（设备刷新率不到的就按刷新率），用限制渲染循环（`requestAnimationFrame` 里按目标帧间隔跳帧）实现，别靠降画质。**左上角显示帧率**（`FPS 58`，小字，半透明，不挡视线；设置里加一个"显示帧率"开关，默认**开**）。
4. **帧率低冒红色网络感叹号**：连续 3 秒平均帧率低于目标的 60%（或低于 20）→ 左上角帧率旁出现一个红色的"信号格加感叹号"图标（像手机信号差时那个，用 canvas 或 CSS 画，不用外部图片），鼠标悬停或点一下弹一句"画面卡了，可以到设置里调低画质或视野"（不用括号）；恢复到目标的 80% 以上 3 秒后图标消失。
5. **太卡自动退出（必要的时候）**：我的定法，作者说"必要的时候"没给数：**连续 10 秒帧率低于 8 → 先自动把画质降一档并弹提示**（"太卡了，画质降到 X"）；降完 **再连续 20 秒低于 5 → 自动存档、退出当前模式回大厅**（弹一句说明）。**猫盾工业里别直接杀进程**：走 `indExit` 的存档路径（任务 145 已经保证不丢东西），先把当前存下来再走；联机局不自动退出，只提示（退出会害队友）。写进 docs/settings.md，数字可调。
6. **三项都太高时提示（取决于性能）**：玩家把画质、视野、流畅度**同时调到最高档附近**（两项或以上在最高两档）时，**测一下当前设备**：开一个 3 秒的小测（只在设置页开着时，用当前画面的实时帧率），如果平均帧率低于目标的 70%，或者 `deviceMemory` / `hardwareConcurrency` 很低，弹一句"你的设备可能跑不动这个组合，画面会卡"，并给一个"调回推荐"按钮（推荐 = 按设备性能算的组合：好设备中高、差设备低）；**只提示，不阻止**。
7. **每个模式都要生效**：寻宝队、惊魂夜、竞速、密室、推推乐、爬塔等主游戏模式都读这三项；**猫盾工业和实验室归 Code2**（任务 168），你这边留好读取接口：`graphicsQuality()`、`graphicsView()`、`graphicsFps()` 返回当前档位（0～3、0～3、0～2）和 `graphicsViewMul()`（视野倍数）、`graphicsFpsTarget()`（目标帧率），并在 docs/settings.md 写清楚。帧率显示和红色图标是**全局的**，在大厅以外的所有模式都有（含工业）。
