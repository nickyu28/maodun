**每档对应的渲染参数**
| 项 | 档 | 具体 |
|---|---|---|
| 画质 | 低 | 像素比 1；抗锯齿关；球、圆柱、圆锥、圆环、圆的分段数 ×0.6 |
| | 中（默认，设备差默认低） | 像素比 ≤ 1.5；抗锯齿开；分段 ×1，跟原来一样 |
| | 高 | 像素比 ≤ 2；分段 ×1.25 |
| | 超高 | 像素比 = 设备原生；分段 ×1.5 |
| 视野 | 正常、稍远、远、超远 | 相机 far 和雾的近远距离 ×1、1.4、2、3；指数雾浓度 ÷ 倍数；纯黑的雾（暗室）不放大 |
| 流畅度 | 正常、流畅、高（默认流畅） | 帧率目标 30、60、120，限制主画面渲染的帧间隔，逻辑照常跑 |
- 设备差 = navigator.hardwareConcurrency 不超过 4，或 deviceMemory 不超过 4。
- **即时生效**：像素比、视野、流畅度、帧率显示。**下次建东西才生效**：分段数（已经建好的模型不变）。**要重开页面**：抗锯齿。设置页里画质那一行标题写了"抗锯齿重开页面才生效"。
- **没有阴影这一档**：现在游戏里没有任何阴影（没有 shadowMap、castShadow），画质档位里就没有阴影；要做的话得给灯和模型加投影，是另一件事。
- 默认流畅度我定的是"流畅 60"，不是"正常 30"：作者原话没写默认，30 会让现在能跑 60 的设备凭空变卡。
- 下拉选择：`choice` 类型的选项都这样画了，别的 choice（快捷栏位置、工业按钮的角）也跟着变。
**左上角帧率和卡顿**
- 左上角 FPS 小字，设置里"左上角显示帧率"开关，默认开；没在画（面板盖住、后台）不显示。
- 红色图标：连续 3 秒低于目标的 60% 或低于 20 帧冒出来，回到 80% 以上 3 秒消失，点一下弹"画面卡了，可以到设置里调低画质或视野"。目标最多按 60 算，量到过超过 65 帧才认 120。
- 自动降档：连续 10 秒低于 8 帧，画质降一档并提示；降完再连续 20 秒低于 5 帧，按上面三种处理。数字在 GFX 常量里，可调。
- 三项太高提示：两项以上在最高两档，设备差的马上在设置页里提示，设备好的量 3 秒平均帧率，低于目标 70% 再弹窗；都带"调回推荐"（设备差：低、正常、60；好：高、稍远、60）。只提示不拦着。
