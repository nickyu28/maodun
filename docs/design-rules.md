# 猫盾工业 · 设计四条（作者 11-12 定，以后所有任务都要过这四条）

1. **所有东西都要符合现实**（除非作者特批）。
2. **对于地球：必须符合（大部分）人类发展史**，从早期人类到现在：先有什么、后有什么，顺序别乱。
3. **大部分东西都得放在主线上**（主线 = 火箭，见 docs/rocket.md、docs/achievements.md）。
4. **所有物品，要么有多重用途，要么是主线上不可避免的一环。** 只用一次又不在主线上的，不做。

怎么用：
- 协调者写新任务前先过一遍这四条；Code 做任务时发现任务和这四条冲突，**不要硬做**，在汇报里写"哪条冲突、我建议怎么改"。
- 作者特批的例外，写进这个文件下面的"特批"一节，没写的就不是特批。
- 不存在的怪（史莱姆、小蘑菇怪、云团、火苗仔、刺球）按第 1 条删掉（见 docs/code2-tasks.md 任务 118）。现实里有的动物（野猪、蜜蜂、狗、猫）保留。
- 删东西永远**不删物品的 key、不清玩家数据**（CLAUDE.md：不再清数据）：只是不再刷、不再有来源，老存档里已有的物品照常能放、能用，没用了的当废料处理方式由任务写。

## 文案规矩（作者 11-13）
- **所有玩家看得到的文字都不用括号**：（）()【】[]，不管是物品说明、提示、面板、按钮、大厅、商店、各个模式、更新公告、成就、教程。括号里的内容要么删掉，要么改成一个短句。
- 说明尽量短，一句话。别写得像 AI。
- 代码里的括号、注释里的括号不管，只管玩家看得到的字符串。

## 交互规矩（作者 11-13）
- **所有弹出来的东西都能按 Esc 退出**：面板、菜单、小游戏、确认框、选落点、地图、成就页、商店、各个模式里的弹层，没有例外；触屏设备同时要有看得见的关闭按钮。Esc 一律关当前最上面的一层，一次一层。
- 新加任何弹出的东西，先想好 Esc 怎么关；冒烟里加检查的时候，顺手断言 Esc 能关。

## 特批
- **深水里能跑、走路不耗体力、速度 ×0.7（任务 107）**：作者要的玩法，特批（作者 11-13 说"行"）。
- **长按左键连续挖，最快每秒 10 下（任务 128）**：玩法速度，特批（作者 11-13）。
- **空手右键摇椰子树（任务 109）**：作者定的操作，特批，不改成长杆（作者 11-13）。
- **原子弹**：核链条的终点，暗处深度，不在主线也只有一次用途，特批（作者 11-13 默认我的建议）。
- **来回进出远征刷新地形（作者 11-13 明确说"不要修复"）**：每次出远征都是一张新随机图，进出一次就换一张，现在没有成本，作者当成小技巧留着。**这不是 bug，谁都别修、别加成本、别限制。** 通关用时估算（任务 124）可以把它算进去。月球是固定地图，不适用。
