# 猫盾工业 · 设计四条（作者 11-12 定，以后所有任务都要过这四条）

1. **所有东西都要符合现实**（除非作者特批）。
2. **对于地球：必须符合（大部分）人类发展史**，从早期人类到现在：先有什么、后有什么，顺序别乱。
3. **大部分东西都得放在主线上**（主线 = 火箭，见 docs/rocket.md、docs/achievements.md）。
4. **所有物品，要么有多重用途，要么是主线上不可避免的一环。** 只用一次又不在主线上的，不做。

怎么用：
- 协调者写新任务前先过一遍这四条；Code 做任务时发现任务和这四条冲突，**不要硬做**，在汇报里写"哪条冲突、我建议怎么改"。
- 作者特批的例外，写进这个文件下面的"特批"一节，没写的就不是特批。
- 不存在的怪（史莱姆、小蘑菇怪、云团、火苗仔、刺球）按第 1 条删掉（见 docs/code2-tasks.md 任务 118）。现实里有的动物（野猪、蜜蜂、狗、猫）保留。
- 删东西永远**不删物品的 key、不清玩家数据**（CLAUDE.md：不再清数据）：只是不再刷、不再有来源，老存档里已有的物品照常能放、能用，没用了的当废料处理方式由任务写。
