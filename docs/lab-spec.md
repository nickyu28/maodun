## 1. 总体

- 实验室不是模式也不是地图：仓库里的一个按钮，点开进入一个工作空间。
- 三个区：
  - 主屋：工作台、固定灶台、订单板、仓库箱。
  - 小院：会下雨，有 1 个水池。
  - 药剂房：炼药台。
- 单人，无计时，自带 HP 100。
- 新文件 `js/18-lab.js`，加进 `index.html` 的 `GAME_FILES`（放在 `17-hub.js` 后面）。
- 爆炸：范围 3 米，40 伤害，毁掉范围内（台面、地上、身上）所有东西，仓库箱除外。
- 毒气：每秒 5 伤害，持续 5 秒。
- 死亡：丢掉身上和台面的东西，锁 60 秒不能再进实验室。仓库里的东西不丢。
- 实验室里的东西不触发原寻宝队的任何逻辑。
- 存档新字段只走 `saveProgress()` / `loadProgress()` 白名单，不动 `SAVE_VER` 和 `DATA_WIPE_VER`。

## 2. 材料与价值

- 宝箱（木/银/金，只在化学寻宝队）只开两类：
  - 原料：煤、铁块、铜-63、沙子、食盐（食盐概率低）。
  - 粒子包：质子数 = 电子数，中子数 0～2 倍质子数。
- 物理器材、药剂、产物一律开不出来，只能合成。橡胶也只能合成。
- 不能卖、没有价值：粒子、原子、原料（煤、铜、沙子、食盐）。
- 例外：铁块能卖，价值 1000。
- 实验室做出的产物（器材、药剂、有用的元素）可以卖，价值按制造难度排，越难越贵，写在 chem.md 的价值表里。
- 价值锚点：铁块 1000，金-197 = 1,000,000（最高）。其余在两者之间，不按真实金价。

## 3. 原子

- 地上的粒子 1.5 秒后按总质子数 Z、中子数 N、电子数 e 自动拼成原子（Z ≤ 26），拼出来不能拆回去。
- 粒子包可以右键拆成单个粒子。
- 拼不出的组合会散开，散开的粒子 5 秒内不再触发拼合。放进器材里的东西不触发地上拼合。
- 不稳定核素按真实半衰期衰变，含离线时间（用时间戳算）：
  - 只在实验室和仓库里衰变，战斗中不衰变。
  - 产物进仓库，仓库满了就消失并提示。
  - 衰变方式用真实的（β⁻、β⁺、电子俘获、α）。
- 自由中子半衰期 611 秒，衰变成 1 质子 + 1 电子。**粒子包、器材（含加速器）里的中子不衰变**；只有散放在地上、台面、仓库里的零散自由中子才按 611 秒衰变。
- 质子 + 电子 → 中子只能在加速器的“转换”模式下做，不计能量。

## 4. 化学反应

- 触发距离统一 0.5 米。
- 气体必须装瓶：
  - 空玻璃瓶在 2 米内会自动装。
  - 没装进瓶的气体 10 秒后飘走消失。
  - 玻璃瓶 = 沙子在灶台上烧。
  - 右键空瓶对着水池或雨 = 一瓶水。
- 灶台上的反应：
  - 氢气 + 氧气 → 水（装瓶的在灶台旁是受控的小火苗，不爆炸）。
  - 碳 + 氧气 → 二氧化碳。
  - 5 碳 + 2 瓶氢气 → 橡胶。
  - 1 碳 + 1 水 → 糖。
  - 铁 + 硫 → 硫化铁。
  - 硫 + 氧气 → 二氧化硫（有毒）。
- 水按真实配比：1 瓶水 = 2 份氢 + 1 份氧。
  - 电解 1 瓶水得 2 份氢气 + 1 份氧气。
  - 合成 2 份氢气 + 1 份氧气得 1 瓶水。
  - 不许出现凭空多出氢气的循环。
- 接触反应：
  - 两个氢原子 → H₂。
  - 钠 + 水 → 氢氧化钠 + 氢气（爆炸）。
  - 钠 + 氯气 → 食盐。
  - 铁挨着水 2 分钟 → 生锈。
  - 水 + 二氧化碳 → 苏打水（装瓶）。
- 爆炸只在两种情况：没装瓶的氢氧混合，或钠碰水。
- 盐水 = 食盐 + 水。
- 没有炼化机，没有空气，没有新手礼包。氢气来自电解，或者用粒子包拼氢原子。

## 5. 物理与电路

没有订单，物理器材必须自己合成。

| 器材 | 配方 | 备注 |
|---|---|---|
| 电线 | 1 铜 + 1 橡胶 = 2 根 | |
| 电池 | 铜 + 铁 + 盐水 | 1.5 V；容量 180 单位，**可以充电**，见下 |
| 开关 | 铜 + 橡胶 + 铁 | |
| 灯泡 | 玻璃瓶 + 铁 + 电线 | 耗电 1 单位/秒 |
| 电阻 | 碳 + 电线 | 耗电 0.5 单位/秒 |
| 电动机 | 2 铁 + 2 电线 | 耗电 1.5 单位/秒 |
| 发电机 | 电动机 + 铁 | 手摇充电，见下 |
| 电解槽 | 瓶 + 2 碳 + 2 电线 | 耗电 2 单位/秒 |
| 升压器 | 2 铁 + 4 电线 | 本身不耗电；电压 ×5，它后面所有用电器的耗电 ×5 |
| 加速器 | 瓶 + 2 电动机 + 4 电线 + 4 铁 | 耗电 1 单位/秒；两个模式，见下 |
| 离心机 | 2 电动机 + 4 铁 + 瓶 + 4 电线 | 耗电 2.5 单位/秒；需要 ≥ 6 V |
| 原子弹 | 3 铀-235 + 6 铁 + 电池 + 2 电线 + 开关 | 不能在实验室里引爆；自带的那块电池是消耗品（不能充电） |

电路：
- 必须手动连线：选电线，点器材 A，再点器材 B，连成一条线。器材堆在一起不会自动连。
- **串联**：电压相加，**每块电池都承担整条电路的全部耗电**。
- **并联**：电压不变，耗电**平均分摊**到每块电池。
- 升压器本身不耗电，但它后面所有用电器的耗电 ×5、电压 ×5。

电池：
- 电池不是一次性的，有“电量”，容量 180 单位。电量存进存档（走 `saveProgress()` / `loadProgress()` 白名单，放进仓库也保留）。
- 灯泡 1 单位/秒对应原来的“一块电池亮 3 分钟”。
- 充电：**发电机手摇**（按住交互）输出 20 单位/秒，平均分给连着的电池，每块最多充到 180。
- 一次动作的时长：聚变 10 秒、离心机 10 秒、电解 5 秒一瓶。
- 校验：加速器 1 单位/秒 × 5（升压器）× 10 秒 = 每块串联电池耗 50 单位（约 28%），所以**一组满电的 7 块电池不充电能做 3 次聚变**；做完后每块补 150 单位，一组 7 块共 1050 单位，手摇 1050 ÷ 20 ≈ 52 秒。目标是“补一组电约 30～60 秒”，具体数值由代码阶段的模拟定。
- 化学寻宝队带入电池：带入的电量就是仓库里的电量，撤离回仓库时带回剩余电量；灯泡 1 单位/秒，一块满电的电池亮 3 分钟。
- 实验室爆炸毁掉范围内的电池，规则不变。
- 价值表里的电池价值不变。

电解：
- 水：需要 ≥ 2 V → 2 份氢气 + 1 份氧气。
- 盐水：需要 ≥ 3 V → 氢氧化钠 + 氢气 + 氯气。
- 熔融食盐：需要 ≥ 4 V → 钠 + 氯气。
- 盐水电解必须有 3 个空瓶，没有就在开始前提示“需要 3 个空瓶”，不让开始；否则氯气会放毒气。
- 电解槽耗电 2 单位/秒，每瓶 5 秒。

加速器：
- **输入**：可以直接放**元素（原子）**，也可以放零散的**质子、中子、电子**。元素就是预先打包好的质子 + 中子 + 电子；聚变和转换时按**所有输入的总质子数 Z、总中子数 N、总电子数 e** 一起算。
- 放进加速器的元素在聚变时被**消耗**（不涉及“拆开”规则）。
- **转换**：质子 + 电子 ↔ 中子，功率 ≥ 1.5 V，不计能量。
- **聚变**：Z 27～92 需要 ≥ Z × 0.5 V，(Z, N) 在 chem.md 聚变表里才成功；**电子数 e 必须等于 Z**，否则散开；不在表里也散开。聚变持续 10 秒。
- 必须有预览：界面上显示当前放进的 Z、N、e 和结果，例如“Z=92 N=146 e=92 → 天然铀 ✓”或“不存在”。
- 例子（见 8.3 的验算）：
  - 天然铀（92, 146）= 2 个铜-63 + 1 个铁-56 + 8 个质子 + 48 个中子 + 8 个电子。
  - 金-197（79, 118）= 2 个铜-63 + 3 个碳-12 + 3 个质子 + 32 个中子 + 3 个电子。

离心机：**3 个天然铀 → 1 个铀-235 + 2 个贫铀**（原来是 10 → 1 + 9）。贫铀仍是不可卖的中间品。每次 10 秒，耗电 2.5 单位/秒。

**铀-235 只能由离心机从天然铀分出，不能聚变直接得到**；天然铀和金-197 只能经加速器聚变得到，宝箱和保险柜里没有。

## 7. 化学寻宝队和正常寻宝队的带入装备

### 7.1 化学寻宝队（只用来收集材料）

现有寻宝队的一个开关，**不是新地图，和原寻宝队没关系**。

- **化学寻宝队里不刷怪物**，只用来收集材料（这条取代之前的“保留怪物”）。
- 选择界面加“普通/化学”切换，复用寻宝引擎（做法和 `js/16-modes.js` 里的超燃分支一样，用模式标记）。原寻宝队行为一点都不变。
- 宝箱（木/银/金）只出原料和粒子包，不卖不结算，没有金币。
- 大金（≤ 4/图）规则不变。

带入（化学寻宝队）：
- **不能带原子弹和药剂**。只能带灯泡、电池、开关，共 6 格，从仓库扣。
- 失败时带入的东西全丢（失败条件见下面“暗室”）。
- 开局前不需要原子弹提示（化学寻宝队带不了原子弹）。

暗室：
- 每张图 50% 概率有，一个大房间。
- 没灯时视野只有 2 米。
- 保险柜只在暗室里，开出：
  - 2–3 个元素（硫、氦-4、氖-20、氩-40、瓶装氢气、瓶装氧气），或
  - 8–14 个粒子包。
- 任何地方都没有铀。
- **暗室概率累加**（作者定）：
  - 化学寻宝队**一局结束（撤离或失败）时，如果这一局没有打开保险柜，暗室概率 +15%**。不管这局有没有暗室、有没有撤离。
  - **打开保险柜就重置为 50%**。上限 100%。
  - 存档字段用 `chemDarkBoost`（存的是比 50% 多出来的那一部分，0～0.5），**不进 `safeBoost`**。
  - 玩家看得到的文字里不提这个累加。
- 一局怎么结束（供代码阶段对照）：撤离成功；40 分钟没撤离（游戏钟从 8:00 走到 24:00，每真实 1 秒走 24 秒，`finishGame(false, "时间超出限制。")`）；中途退出；断线／刷新（下次读档按撤离失败算，`huntRunAbandoned`）。没有怪物，所以没有倒地。失败时带入的东西全丢。

灯：
- 灯泡 + 充好电的电池；开关可带可不带，不带就一直亮。
- 每块电池亮 3 分钟。
- 只对本人可见。
- 预先放一个强度为 0 的 PointLight，用强度开关，不要动态增删光源（r128 会重新编译 shader）。

### 7.2 正常寻宝队（原版）：可选的“带入装备”

- 正常寻宝队的选择界面加一个**可选的“带入装备”**，从仓库带，6 格，白名单：**原子弹、治疗/加速/伤害药剂、弹簧鞋**。
- **不带任何东西时，原寻宝队行为必须和现在完全一样**；宝箱里的药剂和原有规则都不变。
- 实验室做的药剂（治疗/加速/伤害）和弹簧鞋**只在正常寻宝队里使用**，实验室里和化学寻宝队里都用不了。
- 带入的东西从仓库扣掉。放进背包的时机要在 `stashLootBeforeRun()` 之后，不然会被当成宝物又放回仓库。

原子弹：
- **每局最多带 1 个。**
- 使用后消耗：清掉当前地图上所有小怪（包括 Boss 的护卫小怪），**7 分钟内不刷新**；再用一次（只有带了才有）重置计时。
- **对 Boss 有效但不秒杀**：每个原子弹扣 Boss 最大血量的 **30%**，不管联机人数。Boss 的详细设计另有文档，这里只定这条规则。
- 炸死的小怪不掉落，不计击杀奖励。
- 由房主判定，联机消息只认房主，`NET_PROTO` 加 1（代码阶段做，现在是 10，改成 11）。
- 开局前如果带了原子弹，提示一次“你带了原子弹，死了会丢”。

带入装备的结算，**沿用原寻宝队现有规则，不新增一套**。我查了现有代码，现有规则是这样的（`js/09-hunt.js`、`js/01-core.js`），带入的装备按“宝物”（非商店道具）处理：

| 情况 | 现有规则 | 带入装备怎么算 |
|---|---|---|
| 撤离成功 | `completeExtraction`：背上的宝物搬进仓库，商店道具（鱼叉、医疗包、腰包、徽章）留在背包 | 没用掉的回仓库（符合你的要求） |
| 你死了（倒地） | `triggerAgentDeath`：背包里的东西（腰包除外）全部掉在脚边地上，队友能捡 | 掉在地上，撤离后不再归你 |
| 你倒下、队友完成撤离 | `teamExtractWithoutYou`：只保住你上交过的，身上的不算数 | 丢 |
| 全队倒下／离开 | `finishGame(false)` → `forfeitRun`：背包清空 | 丢 |
| 活着中途退出 | `huntQuitAsk` → 同样 `forfeitRun`，清空背包，但不加保险柜累加概率 | 丢 |
| 断线、关页面、刷新 | 存档里 `huntRunActive` 还是真：下次读档 `huntRunAbandoned`，按撤离失败算，背包清空，提示“上一局没撤出去” | 丢 |
| 时间超出限制 | `finishGame(false)` → `forfeitRun`，清空背包 | 丢 |

也就是说“死亡、中途退出、断线”全丢，和你要求的一致，不需要新规则。唯一要新写的是：开局把带入的东西从仓库搬进背包，和撤离成功时没用掉的东西能回仓库（现有规则对非商店道具本来就是进仓库，已经满足）。

### 8.2 默认处理（待作者看）

每条都是“没说清的地方 → 我暂定怎么办”，作者改哪条，我改哪条。

气体和材料：
1. **氧、氯也像氢一样，原子接触成双原子分子**：两个氧原子接触 → O₂，两个氯原子接触 → Cl₂，都是气体，必须装瓶。钠、硫是固体，不装瓶。
2. **1 份气体 = 1 瓶**。“2 瓶氢气”和“2 份氢气”是一回事。1 瓶水 = 2 瓶氢气 + 1 瓶氧气合成，一共 3 瓶气体变 1 瓶水（瓶子回收 2 个）。
3. **沙子烧玻璃瓶：1 沙子 → 1 个瓶，灶台上烧 5 秒**。
4. **氢氧化钠是溶液，装瓶，可以放在台面上**。盐水电解的第三个瓶装它。
5. **氯气、二氧化硫没装瓶会放毒气**（每秒 5 伤害，5 秒），不是 10 秒飘走。装瓶的毒气瓶不会伤人；右键扔出去 = 在落点放一次毒气。
6. **铁锈**：铁块挨着水 2 分钟，变成铁锈。铁锈不能卖，不能做器材，没有别的用。提示一句“铁生锈了”。

电路：
7. **用电器耗电**（已被第 5 节的新规则取代）：每个用电器有自己的耗电（单位/秒），电池容量 180 单位；串联各块都承担全部耗电，并联平均分摊；升压器让它后面所有用电器耗电 ×5。
8. **加速器耗电 1 单位/秒**（不管里面有几个电动机）。
9. **聚变中途断电**：通电不满 10 秒，粒子散开，不扣电池以外的东西。

用途和价值：
10. **糖、苏打水、氢氧化钠**只用来炼药剂；**二氧化碳**只用来做苏打水；**硫化铁**是纯收藏品，可以卖，价值低。这些中间品（糖、橡胶、水、苏打水、氢氧化钠、玻璃瓶、气体、天然铀、贫铀）不能卖；能卖的是铁块、器材、药剂、有用的元素、硫化铁、原子弹（见 chem.md 价值表）。
11. **原子弹只能带进正常寻宝队用**（见 7.2），在实验室和化学寻宝队里都放不出来；能卖。

### 8.3 聚变可达性检查（按第 5 节的电池规则重算）

前提：电池 1.5 V、容量 180 单位；升压器电压 ×5、后面耗电 ×5；加速器耗电 1 单位/秒；聚变持续 10 秒；需要电压 = Z × 0.5 V。

**电压和电池**

n 块电池串联，经 1 个升压器：电压 = 1.5 × n × 5 = 7.5n V；加速器耗电 1 × 5 = 5 单位/秒，**每块串联电池各承担 5 单位/秒**，一次聚变每块耗 5 × 10 = 50 单位。

| 要做的 | 需要电压 | 最少几块电池 | 升压后电压 | 每次聚变每块耗电 | 满电能做几次 |
|---|---|---|---|---|---|
| 金-197（Z=79） | 39.5 V | 6 块（9 V → 45 V） | 45 V | 50 单位（28%） | 3 次（150 ≤ 180） |
| 天然铀（Z=92） | 46 V | 7 块（10.5 V → 52.5 V） | 52.5 V | 50 单位（28%） | 3 次 |
| 作者举的例子 | 9 块 13.5 V → 67.5 V | | 67.5 V | 50 单位 | 3 次，金、铀都够 |

- 两个升压器串联：电压 ×25、耗电 ×25，每块每秒 25 单位，10 秒要 250 > 180，**做不成**。所以聚变只能用 1 个升压器。
- 其他用电的电压也都够：水电解 ≥ 2 V → 2 块；盐水电解 ≥ 3 V → 2 块；熔融食盐 ≥ 4 V → 3 块；离心机 ≥ 6 V → 4 块；转换 ≥ 1.5 V → 1 块。
- 离心机：耗电 2.5 单位/秒、10 秒 = 每块串联电池 25 单位，4 块（6 V）一次每块 25 单位，满电能做 7 次。

**充电（手摇发电机 20 单位/秒，平均分给连着的电池）**

| 一组 | 做 3 次聚变每块耗 | 全组补满要 | 手摇时间 |
|---|---|---|---|
| 7 块（铀） | 150 单位 | 7 × 150 = 1050 | 52.5 秒 |
| 6 块（金） | 150 单位 | 6 × 150 = 900 | 45 秒 |

都落在“补一组电约 30～60 秒”的目标内，具体数值代码阶段用模拟定。

**元素作为加速器输入的验算**（电子数必须等于 Z）

| 目标 | 输入 | 总 Z | 总 N | 总 e | 通过 |
|---|---|---|---|---|---|
| 天然铀（92, 146） | 2 个铜-63（29, 34）+ 1 个铁-56（26, 30）+ 8 质子 + 48 中子 + 8 电子 | 2×29 + 26 + 8 = 92 | 2×34 + 30 + 48 = 146 | 2×29 + 26 + 8 = 92 | ✓ |
| 金-197（79, 118） | 2 个铜-63 + 3 个碳-12（6, 6）+ 3 质子 + 32 中子 + 3 电子 | 2×29 + 3×6 + 3 = 79 | 2×34 + 3×6 + 32 = 118 | 2×29 + 3×6 + 3 = 79 | ✓ |

零散粒子数：天然铀 8 + 48 + 8 = **64** 个零散粒子 + 3 个元素；金-197 3 + 32 + 3 = **38** 个零散粒子 + 5 个元素。

**宝箱粒子包够不够：要多少包**

粒子包 = Z 个质子 + Z 个电子 + N 个中子，N 最多是 2Z。天然铀要的 8 个质子配 **48 个中子（6 倍）**，超出了粒子包的中子上限（2 倍），差额用加速器的“质子 + 电子 → 中子”转换补：每转换 1 次，少 1 个质子、1 个电子，多 1 个中子。

设包里总共有 P 个质子（P 个电子）、N 个中子，转换 c 次：
- 剩下的质子 = P − c = 需要的质子；中子 = N + c = 需要的中子。

| 目标 | 需要（质子 / 电子 / 中子） | 最好情况（每包中子都是 2Z） | 平均情况（每包中子 = Z） | 最坏情况（包里没有中子） |
|---|---|---|---|---|
| 天然铀 | 8 / 8 / 48 | c = 11，P = 19，N = 37，共 **75** 个粒子 | c = 20，P = 28，N = 28，共 **84** 个 | c = 48，P = 56，N = 0，共 **112** 个 |
| 金-197 | 3 / 3 / 32 | c = 9，P = 12，N = 23，共 **47** 个 | c = 15，P = 18，N = 18，共 **54** 个 | c = 32，P = 35，N = 0，共 **70** 个 |

（最好情况：N ≤ 2P 取等号，解 48 − c ≤ 2(8 + c) 得 c ≥ 32/3，取 11；金：32 − c ≤ 2(3 + c) 得 c ≥ 26/3，取 9。）

假设宝箱粒子包的质子数 Z 在 1～26 之间均匀（文档里没规定，这是我的假设），平均一个包约 2Z + N = 40 个粒子，那么：
- 每个天然铀要 **约 2～3 个包**（最少 1 个大包，最多十几个小包）。
- 每个金-197 要约 1～2 个包。
- 一颗原子弹要 9 个天然铀：**675（最好）～ 756（平均）～ 1008（最坏）个包里的粒子**，约 17～25 个平均大小的包；作者估算的“约 700”落在最好～平均之间。

**食盐**

- 一组 7 块电池要 7 份食盐；一组电池充电后可以反复用，不是每次聚变都重做。食盐瓶颈见 chem.md 第 5 节。
