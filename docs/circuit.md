# 电路系统（任务 6 设计文档）

只写设计，不写代码。像我的世界的红石，但信号是一个数，能装进芯片。数是我定的，作者可以改。
只给硬核（悠闲没有电，跟现在一样）。

现在的样子：有电池组、发电机两种电源，用电器（电解槽、电灯、水泵、电炉、压缩机、压力机、第 6 阶段的设备）拿铜线左键点两个设备接线；一个用电器最多接 4 个电源（任务 16）。这些都是**电力线**，下面的**信号线**是另一套，不混。

---

## 1. 信号

- **信号线**和电力线分开：信号线是新物品（工作台 铜线 1 + 橡胶 1 → 信号线 ×4；没有橡胶之前用 铜线 1 + 草绳 1，第 1 期就能做）。拿着信号线左键点两个电路块接起来（跟铜线一样的操作），信号从"输出口"流到"输入口"。
- 信号是一个**整数 0～255**。0 算"没有"，> 0 算"有"。
- 一根线只连一个输出口和一个输入口；一个输出口能接 8 根线（分出去），一个输入口只能接 1 根（要合并用"或"）。
- **有源元件**（芯片、延时、计时、脉冲、检测块、动作块）要吃电：每个 0.05 U/秒，和现在的电池组、发电机接电力线一样。没电就不工作，输出 0。导线、按钮、拉杆、压力板不吃电。
- 每 1 个**电路刻 = 0.1 秒**。信号走一个元件延迟 1 刻（线本身不延迟）。

## 2. 逻辑元件（放在地上或放进芯片）

| 元件 | 输入 | 输出 | 说明 |
|---|---|---|---|
| 与 | A、B | A>0 且 B>0 → 1，否则 0 | |
| 或 | A、B | A>0 或 B>0 → 1 | |
| 非 | A | A=0 → 1，否则 0 | |
| 异或 | A、B | 恰好一个 > 0 → 1 | |
| 比较器 | A、B，模式选 > < = | 成立 → 1 | B 不接时用块上设的数（0～255） |
| 延时 | A | A 延后 t 刻 | t 在块上设，1～100 刻 |
| 计时 | 开关 | 每 t 秒出 1 刻的 1 | t 1～600 秒，开关 0 时不跑 |
| 计数 | 加、清零 | 当前数（0～255，到顶不再加） | 加的上升沿 +1 |
| 锁存 | 置、复位 | 置过就一直 1，复位才回 0 | |
| 脉冲发生器 | A | A 从 0 变 >0 时出 1 刻的 1 | |
| 条件 if | 条件、A | 两个输出：条件成立走"是"口出 A，否则走"否"口出 A | |
| for 循环 | 开始、N、t | 输出口每隔 t 秒出一次 1，一共 N 次，做完"完成"口出 1 刻 | N 1～255，t ≥ 1 刻 |
| while 循环 | 条件 | 条件 > 0 时每隔 t 秒出一次 1，条件变 0 就停 | t ≥ 1 刻，有上限（第 5 条） |

- 元件上的设置（模式、t、N、数）：左键点它开小面板改。

## 3. 检测块和动作块（独立方块，不能放进芯片）

规矩：
- **紧贴着目标放**，放的时候按朝向（玩家面朝哪边就朝哪边）；只看正前方紧挨着的那一个目标（1.5 米内、朝向 ±45°），不隔空。
- 一个块只干一件事。
- 有一个输出口（检测块）或一个输入口（动作块），用信号线接到芯片或元件上。
- 目标不存在、不匹配：检测块输出 0，块上亮红灯，看着它提示"前面没有炉子"；动作块什么都不做，同样红灯提示。

### 检测块（只读一个量）

| 块 | 读什么 | 能对着 | 输出 |
|---|---|---|---|
| 温度检测 | 温度 ÷ 10（取整，最大 255 = 2550°C） | 灶台、石炉、小熔炉、大窑、篝火、反应堆 | 0～255 |
| 库存检测 | 某一种东西的数量（块上选一种） | 仓库箱、炉膛、出料槽、池子（鱼数） | 0～255 |
| 作物检测 | 熟了 1，没熟 0 | 农田一格 | 0／1 |
| 电量检测 | 电池组电量百分比 | 电池组 | 0～100 |
| 日夜检测 | 白天 1、夜里 0 | 不用目标 | 0／1 |
| 盖革检测 | 辐射强度（和盖格计数器一样的数） | 不用目标 | 0～255 |
| 按钮 | 按一下出 1 秒的 1 | 自己（玩家左键点） | 0／1 |
| 拉杆 | 拉上 1、拉下 0 | 自己 | 0／1 |
| 压力板 | 有人或动物站在上面 1 | 自己 | 0／1 |
| 水位检测 | 池子或井的水量（桶） | 池子格、水井（任务 5） | 0～255 |

### 动作块（只做一件事）

| 块 | 信号 > 0 时做什么 | 能对着 |
|---|---|---|
| 放置器 | 每个上升沿从自己的格子里放 1 个（块上选一种）进前面的东西：箱子就是放进去，灶台／窑／熔炉就是投料，池子就是喂鱼 | 箱子、炉子、池子 |
| 取出器 | 每个上升沿从前面取 1 个（选一种）放进自己的格子（10 格） | 箱子、炉膛"做好的"、出料槽里凉了的 |
| 门块 | 开门（0 关门） | 房子的门 |
| 水阀 | 开（0 关） | 水井（任务 5） |
| 风箱开关 | 开风箱（0 关）：炉子升到鼓风 | 装了风箱的炉子 |
| 电力开关（继电器） | 接通前面那根电力线（0 断开） | 一个用电器 |
| 灯 | 亮（0 灭） | 自己 |
| 报警器 | 响铃、屏幕上方出"报警：xx" | 自己 |
| 炸药引爆 | 上升沿引爆前面的炸药／原子弹 | 原子弹（以后的炸药） |

- 放置器、取出器自己有一个小格子（放置器 10 格，左键开面板往里放东西）。
- 配方（工作台，硬核）：
  - 按钮 石头 1；拉杆 木头 1 + 石头 1；压力板 石头 2；灯 玻璃板 1 + 铜线 1。
  - 检测块：铜锭 1 + 信号线 1 + （温度：铁锭 1；库存：木头 2；作物：种子 1；电量：电池 1；日夜：玻璃板 1；盖革：盖格计数器 1；水位：木头 1 + 玻璃板 1）。
  - 动作块：铁锭 2 + 信号线 1 + （放置器、取出器：仓库箱 1；门块：木头 2；水阀：铁锭 1；风箱开关：风箱 1；继电器：铜线 2；报警器：铃铛 1；引爆：硫 2）。

## 4. 芯片

- 芯片是放在地上的一个块，左键打开**画布**（面板里一块 10 × 10 的格子）。从背包把逻辑元件拖到格子里摆好，在格子里拖线连起来。
- 画布边上有输入口、输出口（基础芯片 4 进 4 出），外面用信号线接这些口。
- 关上面板就"封装"了：外面看就是一个块。
- **档次**（工作台）：

| 芯片 | 配方 | 里面最多几个元件 | 口 |
|---|---|---|---|
| 基础芯片 | 玻璃板 1 + 铜线 4 | 8 | 4 进 4 出 |
| 中级芯片 | 玻璃板 2 + 黄铜 2 + 电池 1 + 铜线 6 | 24 | 6 进 6 出 |
| 高级芯片 | 玻璃板 4 + 钢锭 2 + 钻石 1 + 信号线 8 | 64 | 8 进 8 出 |

- 游戏里还没有硅、金、铂，先用已经拿得到的：玻璃板（沙子烧的，当"硅"）、黄铜、钢、钻石（压力机做的）。以后加了硅、金再换。
- **蓝图**：芯片面板里点"存蓝图"，得到一张蓝图（物品，纸 1）；拿蓝图对着空芯片左键，把里面的摆法复制进去（元件要自己身上有，不够提示缺什么）。
- 芯片里不能放芯片（这一版不嵌套）。

## 5. 防崩

- 所有循环（for、while、计时、脉冲）每一圈**至少隔 1 刻**；元件不能把自己的输出直接接回自己的输入（接线时拒绝，提示"不能自己连自己"）。经过别的元件绕回来可以，因为每个元件延迟 1 刻。
- **每帧预算**：一帧最多算 2000 次元件更新，超了下一帧接着算（信号慢一点，不卡）。
- **while 一次最多连着转 1000 圈**；条件一直成立超过 1000 圈（或者 600 秒），这个 while 自动断开，芯片上亮黄灯，屏幕提示"芯片 3 的 while 超时，断开了"，玩家点它重新接上。
- 信号延迟：每个元件 1 刻（0.1 秒），线不延迟。
- 上限：整个家 **40 个芯片、400 个地上的元件／检测块／动作块**（芯片里面的不算地上），信号线 600 根。超了提示"电路太多了"。

## 6. 分三期

1. **第 1 期**：信号线、与、或、非、异或、延时、按钮、拉杆、灯、锁存、基础芯片（8 个元件）。
   - 玩家能做到："按一下按钮灯亮，5 秒后自己灭"（按钮 → 锁存置；锁存 → 灯；锁存 → 延时 50 刻 → 锁存复位）。
   - 验收：冒烟里摆出这个电路，按钮后灯亮、5 秒后灭；放进基础芯片里也一样；超过 8 个元件放不进去。
2. **第 2 期**（不在排队里，等作者点头）：比较器、计数、计时、脉冲、if、for、while、检测块和动作块全套、中级芯片。
   - 玩家能做到："炉温低于 300°C 就自动加煤"（温度检测 → 比较器 < 30 → while → 放置器（煤）对着灶台）。
   - 验收：灶台温度掉到 300 以下自己加煤；while 超时会断开。
3. **第 3 期**（不在排队里）：高级芯片、蓝图、和核那条线（反应堆温度、盖革）、炸药联动。
   - 验收：反应堆温度高了自动报警、关燃料；蓝图复制一块芯片。

## 7. 回家补算（任务 3）

- 补算按 0.1 秒一刻推进电路太慢（30 分钟 = 18000 刻 × 元件数）。办法：补算时电路**按 1 秒一段**推进（每段跑 10 刻，跟实时一样的规则），所以结果和实时一致；检测块、动作块位置固定，按紧贴的目标读写。
- 补算总预算：电路部分最多 0.5 秒真实时间；超了剩下的时间电路不动（提示"家里电路太复杂，离开时只补到 xx 分钟"）。上限跟任务 3 一样 30 分钟游戏时间。

- 信号线：两头的块 id 和口编号。
