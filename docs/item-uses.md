# 猫盾工业 · 物品用途盘点

11-02 夜 Code1 盘的，只读了 js/19-industry*.js，**没改代码**。作者定的原则：每样东西至少两个用途。

怎么数：游戏里自己的「配方」本（`indBookLines()`，硬核）里它当原料做出几样不同的东西，算几个；再加上直接用的（吃喝、穿、当燃料、当工具、放下来起作用、喂动物、施肥浇水之类），每种算一个。
空瓶空桶空钢瓶这种"还给你"的不算用途。烫锭（铜锭（烫）等 13 种）只是锭凉之前的样子、硬岩和天然气喷口是地图上的点，都不列。数字是 11-02 时 main 上的。

## 二、只有 0 或 1 个用途的，各一句建议

（只是建议，做不做、怎么做作者定；好几样一样的合成一行）

- **泥土**：泥土 + 草 → 土坯，便宜的墙和小屋。
- **石油**：大窑里分馏出焦炭和沥青，沥青铺基地的路，走得快。
- **草**：喂羊牛（加进爱吃的）。
- **树枝**：篝火加柴（烧得短）；做火把，远征夜里拿着亮。
- **羊毛**：羊毛床，睡一觉回得更多；或者直接塞进棉衣变暖一点。
- **铜矿、锌矿、铁矿、锡矿、方铅矿、镍矿、铝土矿**：放进粉碎机磨成矿粉，矿粉炼出来多 50%（粉碎机也就多了用途）。
- **锂辉石、锗矿、镓矿**：同上，磨粉多出锭。
- **铀矿**：沙子 + 铀矿 → 铀玻璃板，夜里自己发绿光（做不用电的路灯）。
- **萤石**：炼钢时当助熔剂，时间减半。
- **种子**：多的种子在炉子上烤着吃（饱食一点点），或者喂羊牛。
- **土豆**：土豆 + 铜线 + 锌锭 → 土豆电池（很弱，教学用）；喂羊牛。
- **玉米**：喂羊牛；磨粉做玉米饼。
- **甘蔗**：甘蔗渣当燃料。
- **南瓜**：南瓜灯，放下来亮一晚。
- **烤玉米、腌萝卜、南瓜派、烤仙人掌**：加进狗猫爱吃的，喂了驯服快一点。
- **速度药、回血药**：浇在作物上，速度药让这一季长快、回血药救活冻坏的作物。
- **锡锭**：焊锡，接线时少用一根铜线。
- **青铜锭**：青铜剪刀、青铜钳子，拔刺比铁快。
- **锗锭、镓锭**：做芯片和二极管（电路第 1 期）；镓 30°C 就化，还能做体温计。
- **氯气瓶**：生水消毒，喝了不拉肚子。
- **二氧化硫瓶**：漂白羊毛，白毛衣多 1 点保暖。
- **氟化氢瓶**：在玻璃上刻刻度，做量杯。
- **氢氧化钠**：氢氧化钠 + 草木灰 → 肥皂，洗手治拉肚子。
- **钠**：扔进水里出氢气（另一条做氢的路）；钠灯，比电灯省电。
- **核链条中间品（铀矿粉、黄饼、六氟化铀、芯块、燃料棒）**：链条中间本来就是一步一用，不强求；黄饼可以顺带给玻璃上色。
- **乏燃料棒**：放在反应堆旁边当一点余热。
- **钚**：做核电池（一直 6 V，不用充电）。
- **贫铀罐**：原子弹里代替一半钢（当反射层）。
- **核废料**：粉碎机 + 玻璃 → 玻璃固化块，能垒墙挡辐射。
- **铃铛**：当闹钟，睡到点自动响；挂门上有动物进来会响。
- **指南针**：靠近铁矿、磁石指针会乱晃，拿来找矿。
- **盖格计数器**：远征时靠近铀矿会响，拿来找铀矿。
- **衣服帽子围巾（6 样）、铅围裙、防爆头盔、背包（4 样）**：工作台拆回一半原料。
- **镍电池**：单独一节装进盖格计数器、电灯，用得更久。
- **发电机**：旁边的炉子顺便鼓风（省一个风箱）。
- **汽轮发电机**：排出来的蒸汽烧开水。
- **手摇发电机**：冬天摇着暖身子。
- **变压器**：反过来升压（电池组升到 24 V）。
- **电灯**：放在暖棚里补光，冬天棚里长快一点。
- **压力机**：压煤球（烧得更久）；压铁锭成铁板。
- **粉碎机**：磨普通矿（见上）；石头磨成沙子。
- **离心机**：牛奶分出奶油，做黄油。
- **反应堆**：余热给暖棚、房子供暖。
- **时间加速器**：说明里已经写了以后载具要用，暂不用加。
- **篝火**：上面能烤东西（烤土豆、烤玉米、烤仙人掌），不用灶台。
- **仓库箱、铅箱、床、工作台**：家具一件一用是正常的；床可以加"设复活点"。
- **风箱、出料槽、进料漏斗**：漏斗也能倒水，自动给锅加水。
- **木屋、砖房、大砖房**：屋里睡觉回得更多。
- **木筏**：海边钓鱼（docs/water-fish.md 里已经有方向）。
- **原子弹**：只是炸，不用加。
