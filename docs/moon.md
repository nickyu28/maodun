# 月球（第 2 章）拆分路线图（协调者 11-07，按作者的决定拆）

设定在 docs/rocket.md "火箭之后"一节（月球、火星、固定地图、选落点、资源不刷新、带物资有重量、月兔、插旗、电子电路目标、月球车接人）。这份只管**怎么拆成任务、先后顺序**。

## 作者 11-07 补的两条
- **货运火箭**：可以造只能搭载物品的火箭（没有舱体、不载人），用来从地球往月球补给；铜、硝酸这类月球上没有的东西从地球运（地球上到处都是）。货运火箭降落在月球基地的着陆台（M4 定）。
- 推进顺序：地球 → 月球 → 火星，不能跳。

## 分期（M1、M2 已经拆成任务 82、83；后面的等前面做出来、作者看过再拆）
- **M1 月球固定地图**（任务 82）：固定种子、地貌、不刷新的资源点、存档。
- **M2 选落点**（任务 83）：选址界面，基地位置一旦定下就不能挪。
- M3 月球基地：落点上的基地能用（仓库箱、灶台、电……，沿用地球基地的东西），飞船带来的货物落进仓库箱。
- M4 货物和货运火箭：装货界面（有重量、算进火箭质量）、货运火箭、基地里的着陆台。
- M5 生存：没空气（氧气瓶）、宇航服、昼夜和温度、重力 1/6、没声音、炉子要氧。
- M6 月球资源加工：钛铁矿、斜长岩、橄榄石、KREEP 岩、陨石铁镍块、陨硫铁、月壤、水冰的配方和用处（每样至少两个），月壤种地。
- M7 月兔。
- M8 暗处目标：插旗（225 旗格）、月球上做出电子电路。
- M9 求救信标和月球车来接人（复用任务 50 自动驾驶）。
- M10 回程：月球发射台，自己造燃料，回地球。
- M11 火星解锁（要去过月球）。

## 依赖
月球的玩家入口要等火箭做完（任务 81 起的 7 期）。M1、M2 不用等：先用调试入口（?hcdebug=1 下用函数进）做出来、测出来，真正的入口等火箭发射那一期接上。
