# 设计四条体检（任务 119，11-13，只报告，没改代码）

依据 docs/design-rules.md 四条。数据来源：①脚本数每样东西现在当原料出现在几条配方里、能不能直接吃穿烧用放（只数配方表和物品自带的用途，**代码里写死的特殊用法数不到，所以"只有 1 个用途"的名单可能多报，作者看到不对的告诉我**）；②旧盘点 docs/item-uses.md（11-02，Code1）；③读文档和任务。怪（史莱姆、小蘑菇怪、云团、火苗仔、刺球）归任务 118，这里不重复。

## 一、违反第 1 条（不现实）的

1. **速度药、回血药**：番茄、白菜萝卜在炉子里"熬"出喝了就变快、立刻回血的药水。现实里没有这种效果。建议：回血药改成"草药／绷带"（棉布 + 草木灰，止血）这种现实东西，速度药删掉或改成咖啡因（以后有咖啡再说）。作者定。
2. **时间加速器**：放下后附近设备 ×3。现实里没有。说明里写了"以后载具要用"。建议：删掉，或改成"蒸汽机加速纺车"这类真实的机械增益；作者定。
3. **深水里能跑、走路不耗体力、速度 ×0.7（任务 107，已做）**：现实里游泳不能"跑"，也不会不耗体力。不在特批里。建议：改回"游泳耗体力、速度慢"，或作者特批。
4. **按住左键最快每秒挖 10 下（任务 128，未做）**：现实里一个人一镐一秒做不到每秒 10 镐。建议：作者特批（这是玩法速度），写进 design-rules 的"特批"。
5. **空手拔刺、空手摇椰子树**：椰子树能摇下椰子不真实，要爬树或用杆子打。建议：椰子改成"拿长杆（树枝 + 草绳）打"，别空手；小问题，作者定。
6. **一格水池每格 4 桶、井每小时 1 桶、站水里体温每秒降 0.1°C**：数是游戏化的，现实只看方向（水里确实降温），不算违反。
7. **时间压缩**：一天 20 分钟、作物 3 个游戏日长成、鱼 600 秒长大，游戏化压缩，不算违反（所有游戏都这样），但**作者要的"符合现实"如果包括速度，这几个都要重算**，先别动。
8. **没发现违反的大块**：核链条（铀矿粉→黄饼→六氟化铀→浓缩→芯块→燃料棒→后处理出钚）、电解、压缩气体、空气分离、氯气、氢氟酸，顺序和产物都符合现实，只是简化了。

## 二、违反第 2 条（人类发展史顺序乱）的

说明：顺序从配方依赖链读出来，没有逐局实玩，**以下是可疑的，不是确定的**。

1. **电池（铜 + 锌 + 盐）不需要铁**：伏打电池 1800 年，早于钢（贝塞麦法 1856），顺序对。但**电灯、电解、电炉都能比钢早出现**：现实里电炉炼钢是 1900 年前后，电解铝 1886，都在钢之后。建议：电炉和电解槽配方里加钢（设备的壳），让它们必须在钢之后。**这是我认为最值得改的一条**。
2. **钻石稿（压力机压煤）**：压力机现实里 1955 年才做出人造钻石，游戏里在"有钢和电"之后就能压，比火箭前的很多东西早。可接受，因为压力机本身要钢。不改，留意。
3. **原子弹在火箭前就能做**：现实里先有原子弹（1945）后有火箭入轨（1957），顺序对，只是游戏里它不在主线上，只有一次用途，见第三节。
4. **锂电池、铝架背包**：锂电池（1991）需要铝锭 + 锂辉石，铝要电解（1886），顺序对。
5. **铜被当"一档"的残留（作者问）**：工具六档现在是石、青铜、铁、钢、钻石，铜没有单独工具，对。查到的残留：**黄铜桶（bucket_cu）、铜钳子（钳子用铜锭 2）**，这两样不是"铜档工具"，是容器和夹具，保留没问题；没有成就、提示写"铜器"。主线成就"脱离原始人 = 青铜镐"这条需要 docs/achievements.md 里的链确认是青铜时代的第一步（我没改成就，只报告）。
6. **开局第一个金属是不是铜 + 锡 = 青铜**：铜矿、锡矿都是山地露头（任务 96 之后地面占约 70%），锡还有海边锡砂；100 张图里离出生点 350 米内凑齐铜和锡的图占 97%。现在的顺序是对的：铜矿 → 铜锭、锡矿 → 锡锭 → 青铜 → 青铜稿，**铜不会单独停留成一个时代**。
7. **铅**：古代就有的金属，现在只用于铅箱、铅围裙、反应堆、电磁线圈，用得很晚。现实里铅管、铅釉很早，但游戏里没必要，不算乱。

## 三、不在主线上、又只有一个（或没有）用途的物品（第 3、4 条核心）

主线 = 火箭（docs/rocket.md、docs/achievements.md）：钢、铝、钛（还没做）、塑料、玻璃、铜线、电机、石油、氧、氢、氮、液氧液氢、空气分离、压缩机、冷凝、硅芯片等。下面只列**不在主线**的。数字是脚本数的"配方里当原料几次 + 直接用途"，0 或 1。

### 0 个用途（建议优先处理）
| 物品 | 现在 | 建议 |
|---|---|---|
| 钠（电解熔融盐出的） | 没有 | 扔水里出氢气，或钠灯；或并入"电解熔融盐"的副产品说明，作者定 |
| 核废料 | 没有 | 粉碎机 + 玻璃 → 玻璃固化块（现实做法），或删 |
| 烧坏的设备、烧坏的电池 | 废料 | 拆回一部分金属（拆东西已有），不用加 |
| 氖气瓶、氪气瓶 | 只点元素表 | 氖：氖灯；氪：氪灯泡，等作者定 |
| 冰箱、冷藏箱、氟利昂瓶 | 氟利昂只做冰箱，冰箱存食物保鲜 | 冰箱本身算多用途（保鲜），氟利昂并入冷凝机主线做制冷剂 |

### 1 个用途（不在主线，按类写）
- **泥土**：只开农田。建议：泥土 + 草 → 土坯（便宜的墙），或夯实地基。
- **石油**：只当燃料。主线（煤油）用它，**算主线**，保留。
- **草、树枝**：草做草绳、树枝做小刀。建议树枝加"篝火加柴"、"火把"；草加"喂羊牛"。
- **羊毛**：只做毛线。建议：直接做毛毡垫。小问题。
- **土豆、玉米、甘蔗、南瓜、小麦的炉子用途**：各只有一条食物配方（土豆→烤土豆等）。作物都能喂动物，实际用途不止 1，脚本数不到。**不处理**。
- **烤土豆、烤玉米、南瓜派、腌萝卜、烤仙人掌、烤蘑菇、蘑菇汤、冰淇淋、冰棍、烤肉、肉汤、烤鱼**：食物只当食物，天然就是一个用途，**食物本来就是终点，不处理**（第 4 条应该把"吃"算作一个正当用途，请作者确认食物不用第二个用途）。
- **矿石（铜锌锡铁铝镍锂锗镓方铅矿铀矿萤石）**：都只炼锭。这是主线"矿→锭"的必经一步，**算主线必经，保留**。粉碎机"磨粉多出 50%"能给所有矿一个第二用途，旧盘点里就提过，建议做。
- **钢瓶中间品**：氯气瓶、二氧化硫瓶（做硫酸）、氟化氢瓶（六氟化铀）、氢氧化钠、黄饼、铀矿粉、六氟化铀、芯块、燃料棒、乏燃料棒、钚：核链条每一步只有一个用途，**但整条链是一个整体**。**核链条本身不在火箭主线上**，只通向原子弹和反应堆。建议：作者定核电是"主线支线"，如果是，则整条链算必经，不处理；如果不是，只有原子弹一个出口，需要给反应堆发电之外再给钚一个用途（核电池）。
- **发电机类**（蒸汽发电机、手摇发电机、变压器、太阳能板、地热、风力、小型核电）：各只当电源或变压，**"电源"本身就是设备的用途**，不处理。
- **电灯、灯泡、火把**：只照明，"照明"算一个正当用途。不处理。
- **水泵、水塔、储油罐、储气罐、管道、信号线、按钮、拉杆、与或非异或锁存延时、信号灯**：基础设施类，一个设备一个功能，天然如此。**电路元件**（按钮到锁存）在主线上用得到吗？目前没有任何配方吃它们，是玩家自己搭自动化用的，建议保留，但作者要是严格按第 4 条，它们应该至少被一个主线机器要求（比如发射台控制要用与门）。作者定。
- **压力机**：只压钻石。建议加"压煤球""压铁板"。
- **离心机**：只浓缩六氟化铀。建议：牛奶分出奶油做黄油，或并入核链条（不处理）。
- **反应堆**：只给汽轮发电机供热。建议：给暖棚和房子供暖。
- **粉碎机**：只磨铀矿。同矿石建议（磨粉）。
- **铃铛、指南针、盖格计数器**：各只一个用途（叫动物、指撤离点、看辐射），指南针还做地图。建议：盖格计数器近铀矿响（找矿）、指南针近磁石乱晃，作者定。
- **原子弹**：只爆炸。**不在主线，只有一次用途**。第 4 条的典型：要么特批，要么删。我建议特批（核链条的终点，是设计里的暗处深度），请作者定。
- **衣服类**（棉衣、棉帽、围巾、毛衣、毛帽、毛围巾、防爆服、防爆头盔、铅围裙、4 种背包、3 种鞋）：各只有保暖／挡爆炸等单一用途。"穿"本身是正当用途，不处理。
- **盾、刀、斧铲剪的各档**：工具类，单一用途是正常的，不处理。
- **床、仓库箱、工作台、木屋、砖房、大砖房、石屋、石墙、石地板、木筏、篝火**：家具和建筑单一用途正常。建议：床加"设复活点"，篝火上能烤东西（已有）。
- **月球资源**（钛铁矿、斜长岩、橄榄石、KREEP 岩、陨石铁镍块、陨硫铁、月壤）：脚本数到的用途 0。它们是月球线（火箭返程之后）的资源，**橄榄石、KREEP 岩现在没有配方用**（任务 82 时我按 100 份底线留着）。建议：作者定月球线用途前，保持现状，不算违规。
- **松脂、乳胶、橡胶**：松脂 → 胶水（任务 120 之后），乳胶 → 橡胶，橡胶 → 密封件／管道；用途 1～2，主线的塑料之前用橡胶，**保留**。
- **骨、骨粉**：骨 → 骨粉 → 肥料；骨粉只有施肥一个用途，建议骨加"煮骨汤"，小问题。
- **腐烂的食物**：只当肥料／废料。现实里就是堆肥，保留。
- **火种、燧石、火柴、打火机、干木头**：起火那条的链条，现实顺序对，保留。
- **木盖**：只盖水池格。任务 90 取消蒸发之后，木盖**没有实际作用**。建议：删木盖，或让它挡动物喝水／脏东西掉进去（等任务 91 脏水做了再有用）。**这是违反第 4 条最明显的一个**（只有一个用途，而且这个用途已经是摆设）。
