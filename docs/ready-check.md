### 1.3 已知问题和没验过的
1. **房主中途掉线**：`BOSS_HIT` 的目标是 `huntBigLeader()`，也就是当时的队长。代码里没看到队长换人以后 Boss 血量交接的处理，掉线的队长手里的血量会丢，新队长那边的 Boss 可能是满血。**没人实测过**，我只是读了代码没找到处理。
2. **没有真人联机实测**：BS5 是两个标签页加 stub 模拟的，延迟、丢包、三四个人同时打都没试过。
3. **手感和平衡没人玩过**：docs/boss.md 里估单人拿鱼叉中等一分半到两分钟，困难三四分钟，躲圈时要停手。没有玩家反馈，不知道难不难、无不无聊。
4. **小怪和 Boss 的同步程度不一样**：小怪还是各端各自的，Boss 的血量归房主，队友屏幕上的 Boss 位置、什么时候蓄力可能不一致。
5. **AI 队友不打 Boss**：单人带 AI 时只能自己打，这是设计，但开放后会有人问。
6. **性能**：每帧每只怪都新建一条射线，多一只 Boss 影响不大，没量过低端手机。
7. 联机队员**自己没开开关也会看到 Boss**（跟着房主），但如果队员的版本旧，不认识 `BOSS_HIT`，会被 `NET_PROTO` 拦在房间外，这条是对的。

## 2. 开发者面板（`?dev=1`，T 键）

### 2.1 怎么开、有什么
- `js/05-shop.js` 里 `DEV_MODE` 只看网址 `?dev=1`；有了它按 T 键切换 `#test-panel`，面板里列的是 `TEST_TOGGLES`，每一项点一下开或关，只改本机内存里的常量，不写存档，刷新就没了。另外面板里有一个"超燃赢几局"滑条，改 `BLAZE.roundsToWin`。
- 联机时这些开关只影响自己这一端，不广播。但**客户端本来就能被改**（浏览器控制台里直接改常量），所以它不是"防作弊"的门，只是"别让玩家随手碰到"。

### 2.2 功能清单和建议
**永远藏着，不对玩家开放（破坏经济、破坏难度、泄露不该给的信息）：**
- 通用：无限猫盾币、全解锁
- 寻宝队：无限资金、血量体力锁满、不刷怪、AI 不抢宝箱、无视负重
- 超燃：你自己无冷却、Q 跳过本局、选卡不计时、乱斗一键结束本局、赢几局的滑条
- 惊魂夜：你自己无冷却、关掉友好局、跳过匹配等待
- 竞速：冲刺和技能无冷却、选技能不计时
- 排位：看当前隐藏分。设计上不告诉玩家隐藏分，这个更要藏
- 惊魂夜：相机诊断 HUD（调试用）

**可以做成正式功能，放进设置页（P3 已有框架）：**
- 通用：音效开关、背景音乐开关。设置页"声音"组已经有音量和静音，面板里这两项是重复的，面板里可以删。
- 通用：AI 和路人不戴配饰，"卡的话开这个"。这是性能选项，可以放"显示"组叫"路人不戴配饰"，用 `settingsRegister`。注意规矩要求 AI 戴外观，这个开关只是玩家自己想关，默认要是开着戴。
- 竞速：自选牌，已经挪到大厅了，面板里这一行只剩一句提示，可以删。

**其它测试开关**（不在面板里，各有各的网址参数）：`?hcdebug=1` 猫盾工业（Code2 管，作者要开放）、实验室的 `?labdebug`、`?bossdebug=1`、`?notut=1`。这些各自处理，别混进开发者面板。

**建议：** `?dev=1` 保持现在这样，永远不对玩家开放，也不做入口。上面两个"可做成正式功能"的项移进设置页之后，面板里就只剩调试和作弊。

### 2.3 T 键冲突
- 任务 126 建议元素表用 T、配方表用 C、成就用 H（猫盾工业里）。开发者面板也是 T，只有带 `?dev=1` 才冲突，玩家平时没有，**只影响测试的人**。
- 现在两边都是 `window` 的 keydown，同时响应，会同时弹面板。
- 建议：**开发者面板换键**，不让工业让。换成反引号键 `` ` `` 或者 `Ctrl+Shift+D`，用 `keyRegister('dev', 'panel', '`', '开发者面板', fn, { active: function () { return DEV_MODE; } })` 登记，这样 `?dev=1` 时设置页的按键表里也能看到、能改。
- 另一个做法：保留 T，但工业里在 `ind` 存在时面板不响应。不推荐，测试工业时恰好最想用面板。
